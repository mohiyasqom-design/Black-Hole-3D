# Black Hole Laboratory

**Interactive Gravity Experience.** A physically inspired, real-time black hole you can
poke, feed, fly into and film, built with React and Three.js. Runs fully offline:
no textures, no CDNs, no model downloads. Everything on screen is generated by code.

> Physically Inspired Visualization. The lensing is a ray-traced approximation, not a
> full General Relativity solver. Everything inside the horizon is explicitly hypothetical.

---

## Run it

```bash
npm install
npm run dev        # http://localhost:5173 (also exposed on your LAN, open it on your phone)
npm run build      # production build in dist/
npm run preview    # serve the build
npm run check      # offline sanity check: imports, dependencies, leftovers
npm run generate:assets   # optional Blender pipeline; explains itself if Blender is absent
```

**Android / Termux:** `pkg install nodejs`, then the commands above. Open the printed
Network URL in Chrome. If Rollup's native binary fails on your device, run
`npm i -D @rollup/wasm-node` and add `"overrides": { "rollup": "npm:@rollup/wasm-node" }`
to package.json.

Requires a WebGL 2 browser (any recent Chrome, Edge, Firefox, Safari 15+). Without it you
get a drawn fallback, never a blank page.

## The story (what to try)

1. **Watch the intro.** The void bends starlight, then the disk ignites.
2. **Drag, pinch, scroll.** The photon ring and the lensed back of the disk change with viewpoint.
3. **Add Earth.** It is lit only by the accretion disk.
4. **Lab → Earth → Distance.** Pull it in: Normal → Increased Influence → Orbital Instability →
   Tidal Stress → Severe Deformation → Tidal Disruption. Debris spirals into the disk.
5. **Switch to Stellar.** Same Earth, far more violent tides. Try *Massive Black Hole*: Earth
   crosses the horizon intact.
6. **Drop probe.** Its pulses slow and redden and it never visibly crosses. Watch its clock.
7. **Enter Black Hole.** A 9 s cinematic dive (skippable), then the hypothetical interior, then
   **Go deeper** to the singularity visualization, then **Return to Observation**.
8. **Showcase** hides the UI, adds letterboxing, loops a captioned tour and can **Record** a
   video file with sound.

### Real numbers vs. artistic choices

Shown values come from `src/simulation/physics.js`: Schwarzschild radius, Kerr horizon, ISCO
(Bardeen 1972), static and circular clock rates, circular orbit speed, tidal acceleration across
an Earth radius, tidal disruption radius, and redshift of a radially infalling probe.

Artistic: disk colors are mapped into visible light, the tidal deformation shape, the stellar
tidal radius (really ~30,000 rₛ, compressed to fit the scene and labelled in the UI), the
interior and the singularity.

## Hidden interactions

- **Tap the shadow**: photon ring isolation (only light that looped the hole)
- **Triple-tap the shadow**: telescope view, blurred to EHT-like resolution, near face-on
- **Double-tap anywhere**: cinematic swoop
- **Long-press Earth**: spaghettification
- **Pinch out past the limit**: Deep Space camera
- **Hold the title 1.6 s**, type `gargantua`, or the Konami code: Interstellar-style preset

## Architecture

```
src/
  app/          React root, tiny external stores (no per-frame React renders)
  core/         Engine (render loop, orchestration), derive (per-change physics)
  simulation/   physics.js (real formulas), Simulation.js (orbits, tides, debris, probe, clocks)
  blackhole/    BlackHolePass (ray tracer material), Jets, DiskDust
  earth/        ProceduralEarth, GLBEarth, createEarth (asset abstraction + fallback)
  environment/  SpacetimeGrid, OrbitPath, DebrisField, Probe
  shaders/      all GLSL: black hole, interior/singularity, post, Earth, particles, grid
  effects/      RenderPipeline (render targets + fullscreen passes)
  camera/       CameraRig (touch/mouse gestures), Director (sequences), Tour (showcase)
  audio/        AudioEngine (Web Audio synthesis, hook for local files)
  assets/       AssetRegistry (optional GLB manifest with procedural fallback)
  ui/           HUD, Lab panel, telemetry, clocks, science labels, overlays
  data/         black-hole types, parameter ranges, presets, quality tiers, science copy
blender/        optional asset pipeline (never required)
```

**Why an imperative engine instead of React Three Fiber?** The black hole is one fullscreen ray
tracer fed by a scene render target; a single hand-owned loop keeps passes, render targets and
adaptive resolution explicit, and guarantees React never re-renders per frame. The UI reads
telemetry at 6 Hz. R3F can host the same engine later without changes.

**Render graph** (3 passes): scene → `sceneRT` (color + depth) → ray tracer reads it and writes
HDR `bhRT` (or the interior shader does) → post (upsample, streaks, chromatic aberration, ACES,
vignette, grain, flash, letterbox) → screen. Foreground objects are depth-tested inside the ray
march; background ones are sampled along the bent ray.

### Performance

- Internal resolution is decoupled from the canvas; **AUTO** moves it (and step count, particle
  counts, sky detail) to hold ~45–60 fps. LOW / MEDIUM / HIGH are fixed tiers.
- Rays outside the region of interest skip straight to its bounding sphere; most wide-shot
  pixels never enter the loop.
- Jets and disk clumps are analytic in the vertex shader (one draw call each, no CPU).
- Debris is a preallocated ring buffer; no allocations per frame.

### Failure handling

WebGL 2 missing → Canvas 2D fallback · shader compile failure → safe black hole / interior / Earth
materials · context loss → pause and recover · missing or broken GLB → procedural · UI error →
error boundary keeps the canvas running · repeated frame errors → fallback screen.

## Optional Blender pipeline

Blender is **not** needed to run anything. On a machine that has it (3.6+ / 4.x):

```bash
blender -b --python blender/generate_all.py
blender -b --python blender/generate_all.py -- --no-bake   # faster, flat colors
```

| Script | Output | Used by |
|---|---|---|
| `generate_earth.py` | `earth.glb` (displaced relief, baked albedo, cloud shell, LODs) | replaces ProceduralEarth via GLBEarth |
| `generate_spaceship.py` | `spacecraft.glb` | replaces the procedural probe |
| `generate_black_hole.py` | `debris.glb` (shards, plasma knots, ISCO ring) | orbiting close-up detail |
| `generate_environment.py` | `station.glb` (observation ring station, LOD) | distant laboratory |
| `generate_all.py` | runs all of the above, copies GLBs into `public/assets/models/`, enables them in `manifest.json` | |

The black hole itself stays a shader on purpose: a mesh cannot bend light.

To add your own asset, export a GLB into `public/assets/models/`, add an entry in
`public/assets/manifest.json`, and read it with `registry.get('<key>')`.
